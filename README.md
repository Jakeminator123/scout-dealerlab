# Scout Dealerlab

Public source snapshots for Snyggare dealer, a local dealer/video presentation studio related to Scoutgaming.

- [Live review](https://scout-dealerlab.vercel.app/granskning.html)
- [Reviewer instructions](https://scout-dealerlab.vercel.app/granskning/starttext.txt)
- [Material index](https://scout-dealerlab.vercel.app/granskning/manifest.json)
- [Provisional structure](docs/drift/PROVISORISK-STRUKTUR.md)

This repository contains code, selected documentation and material metadata. Original media, archives, credentials and private operations documents remain outside Git. Public media URLs are in references/work-material.json. A fresh clone does not include the local video archive.

Node 24.21.0 (Volta), npm ci, then START.cmd on Windows when the required local media/configuration is available.

Local work remains on jakob/test. The public branch is generated by scripts/sync-public-repo.ts; it does not include private local Git history. UPPDATERA-GRANSKNING.cmd synchronizes public source before promotion and the release receipt afterwards. No Scoutgaming game-engine or production integration is enabled.
